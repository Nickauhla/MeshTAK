# RAK WisBlock

Plateforme **modulaire** (RAK Wireless) : carte de base + modules (cœur **nRF52840**, radio **SX1262** [[lora]], module **GPS**, capteurs).

## Profil
- **Très basse consommation** (nRF52840 + BLE).
- Modulaire → **propre à industrialiser** (chemin « produit »).
- Demande un peu plus d'intégration/DIY qu'un T-Beam.

## Rôle dans le projet
- Candidat **nœud-relais headless** ([[fleet-roles]]).
- **Chemin produit** pour un device joueur low-power, une fois le concept validé sur [[lilygo-t-beam]].
